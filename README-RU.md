# Kong Empire | ПДД Корея — первая версия

Подготовленный код, ещё не подключён к @KongEmpirePDDbot. Python 3.12, без сторонних библиотек. Dockerfile входит в комплект.

## Что есть
- Picture, Illustration, Safety Sign (1/2 ответа), Sentence (1/2 ответа).
- Карточка Picture 01 с переводами, ключевыми словами и английским заголовком.
- Выбор номера обычным сообщением, продолжение с последнего просмотренного вопроса.
- Предыдущий/следующий показываются только при наличии соответствующего урока. Сейчас один урок.
- Закрытый доступ: администратор определяется только по ADMIN_TELEGRAM_ID.
- /grant ID и /revoke ID доступны только администратору. Это управление доступом, а не подтверждение банковской оплаты.
- /id сообщает пользователю только его собственный Telegram ID.
- Защита пересылки штатным protect_content; съёмку другим устройством не исключает.

## Запуск с телефона через Railway и GitHub
1. Создать личный аккаунт GitHub и приватный репозиторий. Загрузить распакованное содержимое этой папки в корень репозитория. ZIP как единственный файл не подходит.
2. В Railway создать проект из этого репозитория. Используется Dockerfile.
3. В настройках сервиса создать постоянный Volume с точкой подключения /data. Без него доступы и прогресс потеряются при пересоздании контейнера. Включить резервное копирование.
4. В Variables добавить BOT_TOKEN (секрет из BotFather), ADMIN_TELEGRAM_ID (твой числовой ID) и DB_PATH=/data/bot.sqlite3. Не присылать токен в чат и не добавлять его в репозиторий. Если свой ID неизвестен, временно поставить ADMIN_TELEGRAM_ID=0, запустить бота, отправить ему /id, затем заменить 0 на полученное число и перезапустить. До замены никто не получает права администратора.
5. Запустить ровно один экземпляр. Спящий режим отключить, публичный домен и входящие HTTP-порты не нужны: используется long polling.
6. Открыть @KongEmpirePDDbot и отправить /start. Убедиться, что с другого аккаунта уроки закрыты. С аккаунта администратора проверить /grant ID, затем /revoke ID.
7. Не запускать одновременно другой сервис с этим токеном. Если ранее настроен webhook, сначала осознанно отключить старое размещение и webhook. Эта программа его автоматически не удаляет.

Railway: https://railway.com/pricing — проверено 09.09.2026: пробный период с $5 кредитов на 30 дней; Hobby минимум $5/мес с включённым использованием на эту сумму. Перерасход оплачивается дополнительно. Бесплатные лимиты не гарантируют непрерывную работу курса. Перед включением платного тарифа проверить текущую цену и лимиты.

## Материалы
lessons.json: ключ категории, номер как строка, путь к картинке и текст Telegram HTML. Допустимы <b>, <u>. В тексте экранировать &, <, >. Длинные уроки разбивать: sendMessage ограничен 4096 символами. Картинка 01 — ранее согласованная оформленная карточка, а не неизменённая оригинальная фотография. Ключ 3 и 4 предоставлен автором, независимая проверка ПДД не проводилась.

## Ограничения
Это первая учебная версия. Нет видеозагрузчика, редактирования уроков через админку, интеграции канала, автоматических платежей, срока подписки и рассылок. Не содержит интерфейса сбора переводов. Перед продажей цифрового доступа внутри Telegram нужно отдельно проверить требования Telegram Stars, вывод средств и статус продавца. Доступ для тестирования выдаётся вручную командами.

Тестирование: python -m unittest test_bot.py. Пройдены проверки закрытого доступа, прав администратора, выбора номера, сохранения прогресса и отсутствующего урока. Реальный Telegram API не тестировался: токен не подключён.
